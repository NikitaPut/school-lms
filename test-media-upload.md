# Тестирование загрузки медиафайлов в вопросах и ответах

## Сценарий теста

### Шаг 1: Запуск приложения
```bash
npm run dev
```

### Шаг 2: Вход в систему
- Email: `teacher1@eduvault.ru`
- Пароль: `password123`

### Шаг 3: Переход к уроку
1. Открыть курс "Робототехника"
2. Выбрать модуль "Основы робототехники"
3. Открыть урок "Введение в робототехнику"

### Шаг 4: Тестирование загрузки в вопросе
1. Прокрутить вниз до блока "Вопросы и ответы"
2. В поле "Задать вопрос" ввести текст: "Как правильно подключить датчик?"
3. Нажать кнопку "Прикрепить фото или видео"
4. Выбрать изображение (например, screenshot.png)
5. Проверить, что появилось превью изображения
6. Нажать "Отправить"
7. Проверить, что вопрос создан с прикрепленным изображением

### Шаг 5: Тестирование загрузки в ответе
1. Найти существующий вопрос (например, "Какая версия mBlock рекомендуется?")
2. В поле ответа ввести: "Вот пример правильной настройки"
3. Нажать кнопку "Фото/Видео" под полем ответа
4. Выбрать видеофайл (например, demo.mp4)
5. Проверить, что появилось превью видео
6. Нажать кнопку отправки
7. Проверить, что ответ создан с прикрепленным видео

### Шаг 6: Тестирование удаления прикрепленных файлов
1. Начать создавать новый вопрос
2. Прикрепить несколько файлов
3. Нажать на крестик (X) на одном из превью
4. Проверить, что файл удален из списка

### Шаг 7: Тестирование просмотра медиа
1. Найти вопрос с прикрепленным изображением
2. Кликнуть на изображение
3. Проверить, что оно открылось в новой вкладке в полном размере
4. Найти ответ с прикрепленным видео
5. Проверить, что видео воспроизводится с контролами

## Ожидаемые результаты

✅ Файлы успешно загружаются через FileReader
✅ Превью изображений отображаются корректно
✅ Превью видео отображаются с контролами
✅ Можно прикрепить несколько файлов
✅ Можно удалить прикрепленный файл до отправки
✅ После отправки медиа отображается в вопросе/ответе
✅ Изображения открываются в полном размере по клику
✅ Видео воспроизводится с контролами
✅ Имя файла отображается под медиа

## Технические детали

### Типы данных
```typescript
interface Attachment {
  id: string;
  type: 'image' | 'video';
  url: string;
  name: string;
}
```

### Функции
- `handleFileUpload()` - обработка загрузки файлов
- `removeQuestionAttachment()` - удаление файла из вопроса
- `removeAnswerAttachment()` - удаление файла из ответа

### Ограничения прототипа
- Файлы хранятся в памяти (base64)
- При перезагрузке страницы файлы теряются
- В продакшене нужна загрузка в MinIO/S3
