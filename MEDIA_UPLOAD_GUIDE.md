# 📎 Загрузка медиафайлов в вопросах и ответах

## Обзор функционала

Добавлена возможность прикреплять изображения и видео к вопросам и ответам в уроках. Это особенно полезно для:
- **Курса "Пайка"** — можно показать дефекты пайки, правильную технику
- **Курса "Робототехника"** — демонстрация сборки, подключения датчиков
- **Курса "3D моделирование"** — примеры моделей, ошибки
- **Любого курса** — визуальное объяснение проблем и решений

## Возможности

### 📸 Загрузка файлов
- **Изображения**: JPG, PNG, GIF, WebP
- **Видео**: MP4, WebM, MOV
- **Множественная загрузка**: можно прикрепить несколько файлов одновременно
- **Предварительный просмотр**: превью отображается до отправки

### 🗑️ Управление прикреплениями
- **Удаление до отправки**: можно удалить файл перед отправкой вопроса/ответа
- **Визуальное отображение**: превью с именем файла
- **Полноэкранный просмотр**: клик по изображению открывает его в полном размере
- **Воспроизведение видео**: встроенные контролы для видео

### 💬 Интерфейс
- **Кнопка загрузки**: иконка скрепки (📎) рядом с полем ввода
- **Превью файлов**: сетка миниатюр с возможностью удаления
- **Имя файла**: отображается под каждым медиа
- **Адаптивный дизайн**: корректно отображается на мобильных устройствах

## Как использовать

### Задать вопрос с медиа
1. Перейти к уроку
2. Прокрутить вниз до блока "Вопросы и ответы"
3. Ввести текст вопроса
4. Нажать кнопку **"Прикрепить фото или видео"**
5. Выбрать файлы (можно несколько)
6. Проверить превью
7. Нажать **"Отправить"**

### Ответить с медиа
1. Найти вопрос, на который хотите ответить
2. Ввести текст ответа
3. Нажать кнопку **"Фото/Видео"** под полем ответа
4. Выбрать файлы
5. Проверить превью
6. Нажать кнопку отправки (📤)

### Удалить прикрепленный файл
1. Найти превью файла в списке прикрепленных
2. Нажать на крестик (❌) в правом верхнем углу превью
3. Файл будет удален из списка

## Технические детали

### Архитектура

```typescript
// Типы данных
interface Attachment {
  id: string;           // Уникальный идентификатор
  type: 'image' | 'video';  // Тип медиа
  url: string;          // URL или base64 данные
  name: string;         // Имя файла
}

interface Question {
  // ... другие поля
  attachments: Attachment[];  // Прикрепленные файлы
}

interface Answer {
  // ... другие поля
  attachments: Attachment[];  // Прикрепленные файлы
}
```

### Обработка файлов

```typescript
// Загрузка файлов через FileReader
const handleFileUpload = (e: ChangeEvent<HTMLInputElement>, target: 'question' | 'answer', questionId?: string) => {
  const files = e.target.files;
  if (!files) return;

  Array.from(files).forEach(file => {
    const reader = new FileReader();
    reader.onload = () => {
      const attachment: Attachment = {
        id: `att${Date.now()}_${Math.random()}`,
        type: file.type.startsWith('image/') ? 'image' : 'video',
        url: reader.result as string,  // base64 данные
        name: file.name,
      };
      
      // Добавление в состояние
      if (target === 'question') {
        setQuestionAttachments(prev => [...prev, attachment]);
      } else if (questionId) {
        setAnswerAttachments(prev => ({
          ...prev,
          [questionId]: [...(prev[questionId] || []), attachment],
        }));
      }
    };
    reader.readAsDataURL(file);
  });
};
```

### Хранение данных

**Текущая реализация (прототип):**
- Файлы конвертируются в base64
- Хранятся в состоянии React
- Теряются при перезагрузке страницы

**Продакшен (рекомендуется):**

## Ограничения

### Текущие ограничения
- ⚠️ **Размер файлов**: нет ограничений (в прототипе)
- ⚠️ **Хранение**: только в памяти браузера
- ⚠️ **Персистентность**: файлы теряются при перезагрузке
- ⚠️ **Валидация**: нет проверки типов и размеров

### Рекомендуемые ограничения для продакшена
```typescript
const MAX_FILE_SIZE = 10 * 1024 * 1024;  // 10 MB
const ALLOWED_IMAGE_TYPES = ['image/jpeg', 'image/png', 'image/gif', 'image/webp'];
const ALLOWED_VIDEO_TYPES = ['video/mp4', 'video/webm', 'video/quicktime'];
const MAX_ATTACHMENTS = 5;  // Максимум 5 файлов на вопрос/ответ

const validateFile = (file: File): { valid: boolean; error?: string } => {
  if (file.size > MAX_FILE_SIZE) {
    return { valid: false, error: 'Файл слишком большой (макс. 10MB)' };
  }
  
  const allowedTypes = [...ALLOWED_IMAGE_TYPES, ...ALLOWED_VIDEO_TYPES];
  if (!allowedTypes.includes(file.type)) {
    return { valid: false, error: 'Неподдерживаемый тип файла' };
  }
  
  return { valid: true };
};
```
