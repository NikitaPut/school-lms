# 🔧 Исправление просмотра медиафайлов

## Проблема

Пользователи сообщали о двух проблемах:
1. **Видео** можно отправить, но нельзя посмотреть (нет возможности воспроизвести)
2. **Изображения** видно прикрепленными, но нельзя раскрыть в большем масштабе

## Причина

### Для видео:
- Видео отображалось с `controls`, но имело маленький размер (w-32 h-24)
- Контролы были слишком маленькими для удобного использования
- Не было возможности посмотреть видео в полном размере

### Для изображений:
- Изображения открывались в новой вкладке через `window.open(att.url, '_blank')`
- Это не удобно, так как пользователь покидает страницу курса
- Нет возможности быстро вернуться к обсуждению

## Решение

### 1. Модальное окно для просмотра медиа (Lightbox)

Добавлено модальное окно, которое позволяет:
- Просматривать изображения в полном размере
- Воспроизводить видео с полными контролами
- Быстро закрывать просмотр (клик по фону или кнопка X)
- Видеть имя файла внизу экрана

### 2. Улучшенное отображение видео

Вместо маленького видео с контролами:
- Добавлена превью-карточка с иконкой Play
- Клик открывает видео в модальном окне
- Видео автоматически воспроизводится при открытии

### 3. Единый интерфейс просмотра

Оба типа медиа (изображения и видео) теперь открываются одинаково:
- Клик на превью → открытие модального окна
- Полноэкранный просмотр
- Кнопка закрытия в правом верхнем углу
- Имя файла отображается внизу

## Реализация

### Добавленные состояния

```typescript
const [mediaViewer, setMediaViewer] = useState<{ 
  attachment: Attachment; 
  visible: boolean 
} | null>(null);
```

### Новые функции

```typescript
const openMediaViewer = (attachment: Attachment) => {
  setMediaViewer({ attachment, visible: true });
};

const closeMediaViewer = () => {
  setMediaViewer(null);
};
```

### Обновленные обработчики

**Для изображений:**
```typescript
<img 
  src={att.url} 
  alt={att.name}
  className="w-24 h-24 object-cover rounded-lg border border-slate-200 cursor-pointer hover:opacity-90 transition"
  onClick={() => openMediaViewer(att)}  // Было: window.open
/>
```

**Для видео:**
```typescript
<div 
  className="relative w-32 h-24 rounded-lg border border-slate-200 overflow-hidden cursor-pointer hover:opacity-90 transition"
  onClick={() => openMediaViewer(att)}
>
  <video 
    src={att.url}
    className="w-full h-full object-cover"
  />
  <div className="absolute inset-0 flex items-center justify-center bg-black/30">
    <Play className="w-8 h-8 text-white" />
  </div>
</div>
```

### Модальное окно

```typescript
{mediaViewer && mediaViewer.visible && (
  <div 
    className="fixed inset-0 bg-black/90 z-50 flex items-center justify-center p-4"
    onClick={closeMediaViewer}
  >
    <button
      onClick={closeMediaViewer}
      className="absolute top-4 right-4 w-10 h-10 bg-white/10 hover:bg-white/20 rounded-full flex items-center justify-center text-white transition"
    >
      <X className="w-6 h-6" />
    </button>
    
    <div 
      className="max-w-5xl max-h-[90vh] relative"
      onClick={e => e.stopPropagation()}
    >
      {mediaViewer.attachment.type === 'image' ? (
        <img 
          src={mediaViewer.attachment.url} 
          alt={mediaViewer.attachment.name}
          className="max-w-full max-h-[85vh] object-contain rounded-lg"
        />
      ) : (
        <video 
          src={mediaViewer.attachment.url}
          className="max-w-full max-h-[85vh] rounded-lg"
          controls
          autoPlay
        />
      )}
      
      <div className="absolute bottom-0 left-0 right-0 bg-gradient-to-t from-black/80 to-transparent p-4 rounded-b-lg">
        <p className="text-white text-sm font-medium">{mediaViewer.attachment.name}</p>
      </div>
    </div>
  </div>
)}
```

## Технические детали

### Z-index
- Модальное окно: `z-50` (поверх всего)
- Контент страницы: `z-0`

### Размеры
- Максимальная ширина: `max-w-5xl` (1024px)
- Максимальная высота: `max-h-[90vh]` для контейнера
- Максимальная высота медиа: `max-h-[85vh]`

### Анимации
- Плавное появление модального окна
- Hover эффекты на кнопках
- Transition на превью

### Доступность
- Кнопка закрытия с иконкой X
- Клик по фону закрывает окно
- `stopPropagation` предотвращает закрытие при клике на контент
