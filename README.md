## 🛠️ Функциональность для методиста

### Управление курсами (новый функционал!)

**Доступ:** войдите как методист или администратор → меню «Управление курсами»

#### 1. Создание курса
1. Нажмите **«+ Новый курс»**
2. Заполните:
   - Название курса
   - Описание
   - Выберите цвет карточки
3. Нажмите **«Создать»**

#### 2. Добавление модулей (годов обучения)
1. Откройте курс → **«Редактировать»**
2. Нажмите **«+ Добавить модуль»**
3. Введите название (например: "1 год обучения — Основы")
4. Нажмите **«Создать»**

#### 3. Создание уроков
1. Раскройте модуль (стрелка ▼)
2. Нажмите **«+ Добавить урок»**
3. Заполните:
   - Название урока
   - HTML-содержание (поддерживаются теги: h2, h3, p, ul, li, pre, code, strong)
4. Нажмите **«Создать»**

#### 4. Добавление материалов к уроку
1. Откройте урок → **«Редактировать»**
2. В разделе «Материалы урока» нажмите **«+ Добавить»**
3. Выберите тип материала:
   - **Текст** — текстовое описание
   - **PDF** — загрузка PDF-документа
   - **Видео** — видеофайл или ссылка
   - **Ссылка** — внешняя ссылка
4. Заполните название и содержимое
5. Нажмите **«Добавить»**

#### 5. Удаление
- **Курс:** в списке курсов нажмите 🗑️
- **Модуль:** в списке модулей нажмите 🗑️
- **Урок:** в списке уроков нажмите 🗑️
- **Материал:** в списке материалов нажмите 🗑️

## 🔐 Система доступа

### Витрина (каталог)
- Все преподаватели видят **все курсы**
- Доступные курсы: яркая карточка → можно войти
- Недоступные курсы: затемнённая карточка с замком 🔒

### Запрос доступа
1. Кликните на закрытый курс
2. Нажмите **«Запросить доступ»**
3. Методист/админ получит уведомление
4. После одобрения курс станет доступен

### Одобрение заявок
**Для методиста/админа:**
1. Перейдите в **«Администрирование»**
2. Вкладка **«Заявки на доступ»**
3. Нажмите **«Выдать доступ»** или **«Отклонить»**

- ✅ Одобрение заявок на доступ
- ✅ Просмотр журнала аудита

- ✅ Полный доступ ко всем курсам
- ✅ Одобрение заявок на доступ
- ✅ **Управление курсами** (создание, редактирование, удаление)

### Преподаватель
- ✅ Просмотр каталога курсов
- ✅ Вход только в назначенные курсы
- ✅ Отметка прогресса по урокам
- ✅ Запрос доступа к закрытым курсам

- ❌ Не может экспортировать материалы

## 🏗️ Технологический стек

- **Frontend:** React 18 + TypeScript
- **Routing:** React Router v6
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **State Management:** React Context API
- **Build:** Vite

## 📝 Примечания

### Текущая версия (прототип)
- Данные хранятся в памяти (при перезагрузке сбрасываются)
- Авторизация без проверки пароля
- Файлы не загружаются реально (только UI)
- Нет реального бэкенда

### Для продакшена необходимо
- Бэкенд на Spring Boot (Java 21)
- База данных PostgreSQL
- Хранилище файлов MinIO
- Кэш Redis
- JWT-авторизация
- Реальная загрузка файлов
- Интеграция с Google Docs API
