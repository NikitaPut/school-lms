# 🎬 Исправление воспроизведения видео

## Проблема

Пользователи сообщали, что видео открывается в модальном окне, но не воспроизводится. Невозможно нажать кнопку Play.

## Причина

Проблема была вызвана атрибутом `autoPlay` на элементе `<video>`:

```tsx
<video 
  src={mediaViewer.attachment.url}
  className="max-w-full max-h-[85vh] rounded-lg"
  controls
  autoPlay  // ❌ Проблема здесь
/>
```

**Почему это проблема:**
1. Современные браузеры (Chrome, Firefox, Safari) блокируют автозапуск видео со звуком
2. Когда браузер блокирует автозапуск, он может также блокировать отображение контролов
3. Видео выглядит как "зависшее" - нет реакции на действия пользователя

## Решение

Убран атрибут `autoPlay` и добавлены правильные атрибуты для видео:

```tsx
<video 
  src={mediaViewer.attachment.url}
  className="max-w-full max-h-[85vh] rounded-lg bg-black"
  controls
  playsInline
  preload="metadata"
/>
```

### Что изменилось:

| Атрибут | Было | Стало | Назначение |
|---------|------|-------|------------|
| `autoPlay` | ✅ Был | ❌ Убран | Браузеры блокируют автозапуск со звуком |
| `playsInline` | ❌ Не было | ✅ Добавлен | Для корректного воспроизведения на iOS |
| `preload="metadata"` | ❌ Не было | ✅ Добавлен | Загружает только метаданные (быстрее) |
| `bg-black` | ❌ Не было | ✅ Добавлен | Черный фон для лучшего отображения |
| `controls` | ✅ Был | ✅ Остался | Отображает контролы воспроизведения |

## Как это работает теперь

### Последовательность действий пользователя:

1. **Клик на превью видео** → открывается модальное окно
2. **Видео отображается** с черным фоном и контролами
3. **Пользователь нажимает Play** → видео начинает воспроизводиться
4. **Доступны все контролы:**
   - ▶️ Play/Pause
   - 🔊 Громкость
   - ⏱️ Прогресс-бар
   - ⛶ Полный экран
   - ⏩ Перемотка

### Почему это лучше:

✅ **Соответствует политикам браузеров** - нет блокировки автозапуска  
✅ **Пользователь контролирует воспроизведение** - нажимает Play когда готов  
✅ **Быстрая загрузка** - `preload="metadata"` загружает только информацию о видео  
✅ **Корректная работа на мобильных** - `playsInline` для iOS  
✅ **Лучший UX** - пользователь не пугается внезапного звука

## Технические детали

### Атрибут `playsInline`

```tsx
playsInline
```

**Зачем нужен:**
- На iOS видео по умолчанию открывается в полноэкранном плеере
- `playsInline` заставляет видео воспроизводиться внутри контейнера
- Важно для модальных окон и встроенных плееров

### Атрибут `preload="metadata"`

```tsx
preload="metadata"
```

**Значения:**
- `none` - не загружать ничего
- `metadata` - загрузить только метаданные (длительность, размеры) ✅
- `auto` - загрузить весь файл

**Почему `metadata`:**
- Быстрая загрузка модального окна
- Пользователь видит длительность видео
- Экономия трафика
- Видео загружается по мере воспроизведения

### CSS класс `bg-black`

```tsx
className="... bg-black"
```

**Зачем нужен:**
- Черный фон для видео (стандарт для видеоплееров)
- Лучше выглядит, чем прозрачный фон
- Соответствует ожиданиям пользователей
